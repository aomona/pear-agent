# PEAR Agent Vision

## 一文でいうと

PEAR Agentは、現実の作業におけるPDCAをAIと共同で回す実行支援エージェントです。

AIが計画を生成するだけでなく、人間の実行を支援し、実行中に発生した変化を次の計画へ戻します。

## 背景

現実の作業には、遅延、割り込み、待機、失敗、外部状態の変化があります。静的なチェックリストや通常のチャットでは、こうした変化を作業全体へ反映するのが難しいという課題があります。

## PEAR LoopとPDCA

| PDCA  | PEAR Loop |
| ----- | --------- |
| Plan  | Plan      |
| Do    | Execute   |
| Check | Assess    |
| Act   | Replan    |

PEAR Loopは、作業が終わってから振り返るのではなく、実行中に短いサイクルを繰り返します。

## 目指す体験

ユーザーは現在の状態を伝えれば、次の行動と変更後の見通しを受け取れます。中断しても会話の続きを復元するのではなく、作業の最新状態から再開します。

## 非目標

- 完全自動化によって人間を作業から排除すること
- すべてのドメインを一つの画面で表現すること
- LLMに任意コードを生成・実行させること
- 最初から汎用SDKやMarketplaceを完成させること
